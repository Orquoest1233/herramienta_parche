# Krita parch tool
A Krita plugin that implements a Photoshop-style patch tool with real-time transformation.

## Characteristics

- Free Transform: Move and rotate the source area with instant preview.

- Organic Smoothing: Box Blur and Gaussian Blur algorithms for seamless transitions.

- Performance Mode: Adjustable quality settings to maintain smooth performance on processors.

## how to use the tool
The plugin is located in the tools section.
- Drag zone/Zona de arrastre: To simulate a drag similar to that of the Photoshop patch tool.
Below you can drag along the X or Y axes, or rotate the patch selection.

- quality/calidad:This allows you to preview the drag in better or lower quality at the cost of some CPU performance.

- Feathered edge smoothing: Edges can be smoothed in a box or Gaussian manner.

## Installation

The current version of the plugin is built for Krita 5.2.16
You can download the latest version of the plugin from the releases page.

## Plugin installation
Since version 2.0, the plugin can be installed as a Python extension. In Krita, go to Tools › Scripts › Import Python Plugin from File... and select the .zip file you downloaded.
